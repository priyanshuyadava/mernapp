# MERN App

Basic MERN stack project.

## Structure
- `server/` — Node.js + Express backend with MongoDB connection (Mongoose)
- `client/` — React frontend

## Run locally

### Backend
```
cd server
npm install
npm start
```

### Frontend
```
cd client
npm install
npm start
```

MongoDB should be running locally on default port 27017 (or set `MONGO_URI` env variable).
